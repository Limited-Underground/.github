# Limited Underground

Projects for off-grid communication, Android and Windows. Visit [limitedunderground.com](https://limitedunderground.com).

## Limited Underground MeshTrail

Open-source messaging, status and location sharing beyond cell coverage. V1 is in development for a limited public test on the Heltec V4.

- [MeshTrail Firmware](https://github.com/Limited-Underground/Trail) — authenticated board-to-board messages have passed bench tests. Group messaging and field testing are pending.
- [MeshTrail App](https://github.com/Limited-Underground/Trail/tree/main/android) — Android companion. Pairing has passed bench tests. Protected phone-to-phone messaging still needs a hardware check.
- [MeshTrail Repeater](https://github.com/Limited-Underground/Trail/blob/main/docs/PRODUCT_BOUNDARIES_V0.md) — radio relay in PC testing. Hardware tests are pending.
- [Console](https://github.com/Limited-Underground/Trail/blob/main/docs/PRODUCT_BOUNDARIES_V0.md) — standalone touchscreen interface with a PC prototype. Hardware tests are pending.
- [Server](https://github.com/Limited-Underground/Trail-Server-Progress) — optional server. Feature work is planned after V1.
- [Gateway](https://github.com/Limited-Underground/Trail-Server-Progress) — radio-to-server bridge. Radio integration is planned after V1.
- [Tracker](https://github.com/Limited-Underground/Trail/blob/main/docs/TRACKING_DEVELOPMENT_PLAN.md) — standalone location tracker planned after V1.
