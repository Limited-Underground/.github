# Limited Underground

Limited Underground builds practical hardware and software for independent, offline, and field use.

## Open hardware and field systems

- [Limited Underground Trail](https://github.com/Limited-Underground/Trail) — an offline-first ESP32, LoRa, BLE, and Android trail communication project under active development.
- [Limited Underground Display](https://github.com/Limited-Underground/Display) — a separate open-source ESP32 display and vehicle-data project.
- [Limited Underground Trail Server Progress](https://github.com/Limited-Underground/Trail-Server-Progress) — public milestones for the privately developed optional Trail Server and gateway.
- [Limited Underground Firmware Loader](https://github.com/Limited-Underground/Firmware-Loader) — a Windows utility for inspecting and loading supported Limited Underground firmware.
- **Limited Underground Trail App** — the Android client currently developed with Trail; a separate public repository is planned when that project boundary is ready. iPhone support is a future goal.

## Desktop software

- **Husky Performance by Limited Underground** — Windows automotive diagnostics and analysis software. [Public demonstration releases](https://github.com/Limited-Underground/Husky-Performance-Releases).
- **Small Business Suite by Limited Underground** — Windows tools for practical small-business workflows. [Public trial releases](https://github.com/Limited-Underground/Small-Business-Suite-Releases).

Project details and current public status are available at [limitedunderground.com](https://limitedunderground.com).
